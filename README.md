**MyCDR** turns raw call records into trunk quality, cost and margin.
Carriers argue about money with numbers; this is where the numbers come
from.

**EaseDial Portal** is tenant-scoped, so a customer sees their traffic and
nobody else's. That boundary is the whole product.

**RouteForge LCR2** prices NPANXX and picks second-lowest-cost routes,
because wholesale voice is not actually won by being cheapest.

**Glyph Toys** is twelve animations for a 13×13 LED matrix. A circle of
radius *r* there lands on 8, 12, 16, 32, 28, 40 pixels — not even
monotonic. So I stopped drawing circles and built from what the grid
renders exactly. **I measured it before I redesigned it.**
