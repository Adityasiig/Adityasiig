**[MyCDR](https://github.com/Adityasiig/cdr-direct)** — turns raw call
records into trunk quality, cost and margin. Carriers argue about money
with numbers; this is where the numbers come from.
<sub>`Python` `Flask` `DuckDB`</sub>

**[EaseDial Portal](https://github.com/Adityasiig/easedial-portal)** —
tenant-scoped, so a customer sees their traffic and nobody else's. That
boundary is the whole product. <sub>`TypeScript` `Next.js`</sub> ·
[live](https://portal.easedial.com)

**[RouteForge LCR2](https://github.com/Adityasiig/routeforge-lcr2)** —
prices NPANXX and picks second-lowest-cost routes, because wholesale
voice is not won by being cheapest. <sub>`TypeScript` `LCR`</sub>

**[Glyph Toys](https://github.com/Adityasiig/glyph-radar)** — twelve
animations for a 13×13 LED matrix. A circle of radius *r* there lands on
8, 12, 16, 32, 28, 40 pixels — not even monotonic. So I stopped drawing
circles and built from what the grid renders exactly.
<sub>`Java` `Android`</sub>
