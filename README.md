## 🚀 About Me

<img align="right" width="300" src="./assets/profile/banner.png" alt="" />

🔭 &nbsp;Telecom DevOps Engineer at **Crown IT Solution**, where I started
as a VoIP NOC Engineer in August 2025.

📡 &nbsp;I run around **82 production servers** — mostly **OpenSIPS** and
**FreeSWITCH**, plus the routing and rate decks behind them.

📊 &nbsp;I build **CDR ingestion and margin analytics**: the pipelines that
turn raw call records into trunk quality, cost and revenue.

🔐 &nbsp;I also do **authorized security testing** — web, API, network and
VoIP.

🧩 &nbsp;For fun I write things like **Glyph Toys**, twelve animations for a
