# Profile assets — dark egoist theme

Seven SVGs, generated by `ego.py`:

```sh
python3 ego.py   # writes out/, then copy up a level
```

| File | What it is |
| --- | --- |
| `ego-banner.svg` | name, the claim, 82 tally marks, travelling rule |
| `ego-rule-*.svg` | numbered section headers, 01–04 |
| `ego-creed.svg` | the four "I do not…" lines |
| `ego-closer.svg` | closing statement and contact |

## Voice

Short, certain, first-person. It only works if every line is
**specific** — a number or a named system. "I build scalable solutions"
is noise; "82 production servers" is a claim someone can check.

The creed section commits to measuring before claiming, so the README
also names what has *not* been verified (Glyph Toys has never run on
real hardware). Dropping that line would make the rest dishonest.

## Third-party widgets

Checked live before use:

| Service | Used for | Status |
| --- | --- | --- |
| `img.shields.io` | badges | 200 |
| `skillicons.dev` | tech icons | 200 |
| `github-readme-stats.vercel.app` | repo pin cards | 200 |

Both accept custom hex, so they match the palette rather than fighting
it. **Avoid** `github-readme-activity-graph.vercel.app` and
`github-profile-trophy.vercel.app` — both return HTTP 402 (over quota)
and render as broken images.

No contribution-stats widgets. Work, not activity metrics.

## Constraints

Camo strips scripts, external references and web fonts, so assets must
be self-contained with a generic font stack and an opaque background
(or they break on the light theme).

Nothing may depend on animation: an element starting at `opacity="0"`
is invisible wherever SMIL does not run. Everything rests at its final
state; animation only dips and returns. Verified by stripping every
`<animate>` and re-rendering.

Never estimate text width — `letter-spacing` is not in any guess. Use
`text-anchor="end"` for right-aligned text.
