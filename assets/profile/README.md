# Profile assets

Two SVGs, generated by `minimal.py`:

- `head.svg` — name, role, one line, a breathing availability dot
- `divider.svg` — hairline rule with a slow accent tick

Everything else in the profile is plain Markdown on purpose: it stays
readable in any client and can be edited without running anything.

```sh
python3 minimal.py   # writes out/, then copy up a level
```

## Constraints that are not stylistic

These were all learned the hard way; breaking them silently breaks the
page for some readers.

**Nothing may depend on animation.** GitHub's camo proxy preserves SMIL,
but Markdown previews, RSS readers and reduced-motion settings do not run
it. Anything animated must be drawn at its *final* state, with the
animation only dipping away and returning. An element that starts at
`opacity="0"` is invisible wherever animation does not run — this once
hid the name entirely.

**Set coordinates up front.** An animated `x` with no initial value
renders at 0 and clips off the left edge.

**No scripts, external references or web fonts.** Camo strips all three.
Fonts must be a generic stack.

**Opaque black background rect on every asset,** or it breaks on GitHub's
light theme.

**Do not estimate text width.** `letter-spacing` is not in any guess you
can make; anchor right-aligned text with `text-anchor="end"` instead.
