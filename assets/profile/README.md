# Profile assets — sumi-e theme

Generated by `sumi.py` from the ink-wash painting:

```sh
python3 sumi.py   # writes out/, then copy up a level
```

| File | What it is |
| --- | --- |
| `sumi-banner.png` | hero crop, title burned into an ink band |
| `sumi-strip.png` | thin ink divider |
| `sumi-side.png` | tall crop beside the projects table |
| `sumi-rule-*.svg` | numbered section headers, 01–04 |

## Palette

Taken from the painting, not invented:

```
ink    #0a0a0a   the storm
paper  #e8e2d6   the sky
blood  #8e2429   the ribbon — the only colour in the piece
```

**One accent per view.** The ribbon reads because everything around it
is monochrome. Adding a second colour breaks the whole thing.

## Things that bit, and why they are done this way

**The source is rotated.** It is a portrait file holding a landscape
composition. `load()` rotates +90; −90 looks plausible in a thumbnail
but puts the sky underneath.

**No kanji in generated images.** The build container has no CJK font,
so cairosvg renders 墨 as a tofu box, and no font is guaranteed on the
renderer either. Kanji lives only in the README's Markdown text, where
the browser resolves it.

**The title is composited into the PNG,** not shipped as an overlay SVG.
GitHub Markdown cannot layer images — no CSS, no positioning — so an
overlay would just stack underneath.

**The title sits on a solid ink band,** not just a gradient scrim. The
lower-left of the crop is bright paper and pale type on it was
unreadable. A band guarantees contrast wherever the crop lands.

**PNGs are quantised to 192 colours.** The artwork is near-monochrome,
so a palette costs nothing visually and took the set from ~2.1MB to
~870KB.

## Third-party widgets

Checked live before use — `img.shields.io`, `skillicons.dev` and
`github-readme-stats.vercel.app` (pin cards only), all 200. All accept
custom hex, so they match the palette.

**Avoid** `github-readme-activity-graph.vercel.app` and
`github-profile-trophy.vercel.app` — both return HTTP 402 (over quota)
and render as broken images.

No contribution-stats widgets. Work, not activity metrics.

## Constraints

Camo strips scripts, external references and web fonts, so SVGs must be
self-contained with a generic font stack and an opaque background.

Nothing may depend on animation: an element starting at `opacity="0"`
is invisible wherever SMIL does not run. Everything rests at its final
state; animation only dips and returns. Verified by stripping every
`<animate>` and re-rendering.

Never estimate text width — `letter-spacing` is not in any guess. Use
`text-anchor="end"` for right-aligned text.
