# Profile assets

Generated by script, not hand drawn. The hero is a SIP console: a scan
sweep across the panel, SIP messages travelling the signalling path,
CDR bars moving, a blinking live marker.

Palette is the portfolio's: pure black, white, `#d71921`, the same
greys. No gradients.

## Constraints these are built to

- **Animation is an enhancement, never a dependency.** SMIL survives
  GitHub's camo proxy (verified by fetching through it), but anything
  that starts at `opacity="0"` and animates to 1 disappears entirely
  where animation does not run. Every element here is visible at rest;
  the animations use `keyTimes` to hide briefly and then reveal, so a
  frozen first frame is the finished picture rather than an empty one.
- **No scripts, no external references, no web fonts.** Camo strips all
  three, so anything relying on them renders blank.
- **An opaque black background rect on every asset**, or they look
  broken on GitHub's light theme.
- **Positions set up front.** An animated `x` with no initial value
  renders at 0 and clips off the left edge in a static render.

## Regenerating

`hero.py` builds the hero; `parts.py` builds the section rules and the
signal strip. Both write straight into this folder.
